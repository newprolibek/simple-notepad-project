Object-oriented Programming, Project
====================================

## Notepad

The project is a GUI notepad application created using Qt.

## Core features

The project contains the following basic features: an `Edit` menu (undo, redo, cut, copy, paste, select all), text case transforms (uppercase, lowercase, capitalize, sentence case, swap case), rich text formatting (bold, italic, underline), find and replace, word frequency analysis, and a status bar with live word and line counts.

It also contains two required features:
1. **Exception handling**

On errors when reading or writing files, and in cases where the file is not found, the program displays a `QMessageBox::critical`.

2. **Spell checking**

The dictionary is loaded once at startup from `data/words.txt` into a `std::set<std::string>`. Highlighting is implemented through a `QSyntaxHighlighter` subclass (`spell_checker_highlighter`) that scans each text block with the regular expression `[A-Za-z]+`, lowercases every match, and underlines it with a red `SpellCheckUnderline` whenever the word is missing from the dictionary.

When the user right-clicks a highlighted word, the standard context menu is filled with up to 5 correction candidates produced by `spell_checker::get_suggestions`. Candidates are generated by three single-edit operations applied to the normalized (lowercased, non-alphabetic stripped) word:
- Replacing each letter with every other letter from `a` to `z`.
- Removing one letter at a time.
- Inserting every letter from `a` to `z` at every position.

Each generated variant is looked up in the dictionary, and the first five matches are returned. Selecting a candidate replaces the word at the cursor with the chosen suggestion.

## Optional features

1. **Cursor line / column indicator**

A permanent widget on the right side of the status bar displays the current cursor position as `Line: X  Col: Y`. It is updated through the `QTextEdit::cursorPositionChanged` signal, which reads the line from `QTextCursor::blockNumber` and the column from `QTextCursor::positionInBlock`.

2. **Font change**

The `Format > Font...` menu item opens a `QFontDialog` initialized with `Helvetica [Cronyx]` at 10 pt. The chosen font is applied to the current selection, or to the entire document when nothing is selected, by merging a `QTextCharFormat` with the new font into the cursor.

3. **Text color picker**

The `Format > Text Color...` menu item opens a `QColorDialog`. The selected color is applied to the current selection, or to the entire document when nothing is selected, by merging a `QTextCharFormat` with the new foreground color into the cursor.

4. **Zoom**

The `View` menu provides three zoom actions:
- `Zoom In` (`Ctrl++`) — increases the font size via `QTextEdit::zoomIn`.
- `Zoom Out` (`Ctrl+-`) — decreases the font size via `QTextEdit::zoomOut`.
- `Reset Zoom` (`Ctrl+0`) — restores the original font size captured at startup from `editor->font().pointSizeF()`.
